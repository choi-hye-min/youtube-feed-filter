# Hidden Reason Message

## Home and Watch Pages

1. Load `src/` as an unpacked extension and enable filtering.
2. Choose a threshold that will match visible recommendations.
3. Open the YouTube home page and wait for a matched card to be processed.
4. Confirm YouTube's hidden-video result card appears.
5. Confirm the previous `동영상 숨김` text changes to `[N일전 업로드]` on the first line and the video title on the second line.
6. Repeat on the `/watch` recommendation list.
7. Confirm undo and feedback buttons remain usable.
8. Confirm the browser console has no extension errors.
